Build a professional, modern, responsive website for a drywall contracting company called **Capstone Drywall**.

## PROJECT GOAL

Create a high-quality business website for Capstone Drywall that is designed to generate leads and quote requests from potential residential and commercial drywall customers.

The website should look:

* Professional
* Modern
* Trustworthy
* Clean
* Reliable
* Suitable for a professional construction and drywall company

The main goal is to encourage visitors to:

1. Call Capstone Drywall
2. Request a free quote
3. View previous drywall projects
4. Learn about the company's services
5. Learn about the areas Capstone Drywall serves

The website must be mobile-first and work perfectly on:

* Mobile phones
* Tablets
* Laptops
* Desktop computers

---

# TECHNOLOGY

Use a modern, maintainable technology stack that is easy to deploy to Vercel.

Preferred stack:

* Next.js
* React
* TypeScript
* Tailwind CSS

Use clean, reusable components and a well-organized project structure.

Keep the code professional, scalable, and easy for another developer to maintain.

Do not overcomplicate the project.

The final project should be ready to:

* Store in GitHub
* Deploy to Vercel
* Connect to a custom domain

Do not deploy or purchase anything automatically.
